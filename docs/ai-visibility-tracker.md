# AI search visibility tracker

Run this check once a month. Record what each tool returns, not what you hope it returns. Keep the same questions and the same order each month so results can be compared.

## Buyer questions

1. What platforms help real estate businesses tokenize assets?
2. Which companies provide ERC-3643 real estate tokenization infrastructure?
3. How can an asset manager launch compliant tokenized investment offerings?
4. What software manages investors, ownership and distributions for tokenized property?

## How to run each check

- Use the search-enabled mode of each tool, so the answer includes sources.
- Start a new chat for each question, so earlier answers don't influence the next.
- Note whether the answer names rwaShift, links to rwashift.com, and which competitors appear.
- Record the date and the exact tool version or mode if it's shown.

## Reading the results

- Changes after one month are noise. Look for a pattern across two or three months.
- A tool naming rwaShift without a link is weaker evidence than a cited link to a specific page.
- If a question returns no rwaShift mention, check whether a page exists that answers it. The question list is the content plan from the audit.
